# Kritika_testingFramework
# 🧪 Test Automation Execution Platform

A scalable and production-ready **Test Automation Framework** built with **Spring Boot 3** and **Selenium WebDriver**, designed to centrally manage, execute, and analyze automated **UI and API tests** through a modern web interface.

This project demonstrates real-world automation architecture, clean separation of concerns, and extensibility for future enhancements.

---

## 🚀 Key Features

- Selenium-based automated test execution engine  
- Real-time execution status and test results  
- Parallel test execution support  
- Clean, modular, and extensible architecture  

---

## 🧰 Technology Stack

### Backend
- Java 17  
- Spring Boot 3.2  
- Spring Web (MVC & REST)  
- Spring Data JPA  
- Hibernate  
- Lombok  

### Frontend
- Thymeleaf  
- HTML5  
- CSS3  

### Automation
- Selenium WebDriver 4  

### Database
- H2 (In-Memory – Development)  
- MySQL (Production Ready)  
  

### Build Tool
- Maven  

---

## 📋 Prerequisites

Before running the application, ensure the following are installed:

- Java 17 or higher  
- Maven 3.6+  
- Google Chrome or Mozilla Firefox  
- Compatible WebDriver binaries (ChromeDriver)
